# mn-sms

[English](README.md) · **Монгол**

Монголын үүрэн холбооны операторуудын — **Юнител**, **Мобиком**, **Скайтел**,
**Жи-Мобайл** — өөрсдийнх нь SMS гарцаар нэг клиентээс мессеж илгээнэ. Та дугаар болон
текстээ өгөхөд тухайн дугаар аль операторынх болохыг тодорхойлж, тэр операторын гарц руу
хүсэлт илгээдэг.

- Гадны сан огт ашиглаагүй. Node 18+ (суурь `fetch`-ийг ашиглана). ESM болон CommonJS,
  TypeScript төрөлтэй.
- Дугаарын эхний хоёр оронгоор таамаглахгүй, албан ёсны дугаарын хуваарилалтаар чиглүүлнэ.
- Гарц бүрийн жинхэнэ хариуг уншина: дөрвөн гарцын гурав нь татгалзсан үедээ ч HTTP `200`
  буцаадаг.
- Нэвтрэх мэдээллийг үр дүн, алдааны мессеж, лог руу хэзээ ч гаргахгүй.

> **Энэ бол SMS зуучлагч үйлчилгээ биш.** Энэ сангийн ард дундын ямар ч бүртгэл байхгүй.
> Мессеж илгээх оператор бүртэйгээ та өөрөө гэрээ байгуулсан байх шаардлагатай —
> [Операторуудаас юу авах шаардлагатай вэ](#операторуудаас-юу-авах-шаардлагатай-вэ) хэсгийг
> үзнэ үү.

## Суулгах

```bash
npm install mn-sms
```

## Ашиглах

```ts
import { createSmsClient } from "mn-sms";

const sms = createSmsClient({
  // Зөвхөн гэрээтэй операторуудаа тохируулна.
  unitel: { apiKey: process.env.UNITEL_API_KEY! },
  skytel: { id: process.env.SKYTEL_ID!, src: process.env.SKYTEL_SRC! },
  mobicom: {
    baseUrl: process.env.MOBICOM_BASE_URL!,
    serviceName: process.env.MOBICOM_SERVICE_NAME!,
    username: process.env.MOBICOM_USERNAME!,
    from: process.env.MOBICOM_FROM!,
  },
  gmobile: {
    username: process.env.GMOBILE_USERNAME!,
    password: process.env.GMOBILE_PASSWORD!,
    from: process.env.GMOBILE_FROM!,
  },
});

const result = await sms.send({ to: "99112233", message: "Таны код: 1234" });

if (!result.ok) {
  console.error(result.gateway, result.error?.code, result.error?.message);
}
```

Эсвэл орчны хувьсагчаас уншуулж болно (хувьсагчийн нэрс [.env.example](.env.example)-д бий):

```ts
import { configFromEnv, createSmsClient } from "mn-sms";

const sms = createSmsClient(configFromEnv());
```

### `send()` хэзээ ч exception шидэхгүй

Амжилттай, амжилтгүй аль ч тохиолдолд үр дүнг объект хэлбэрээр буцаана. Тиймээс хоёуланг
нь нэг ижил аргаар бүртгэж болно:

```ts
{
  ok: false,
  to: "91112233",            // 8 оронтой болгож цэвэрлэсэн дугаар
  operator: "skytel",        // дугаарыг эзэмшигч оператор
  gateway: "skytel",         // хүсэлт очсон гарц
  statusCode: 200,           // тийм, 200 — доор тайлбарласан
  request: { method, url, params },   // илгээсэн хүсэлт, нэвтрэх мэдээлэлГҮЙ
  response: "ERROR: 202 not authenticated",   // гарцын хариу, яг байгаагаар нь
  error: {
    code: "rejected",
    gatewayCode: "202",
    message: "not authenticated — wrong id, or the calling IP is not on the Allowed IP List",
  },
}
```

| `error.code` | Утга | Сүлжээгээр хүсэлт явсан уу? |
| --- | --- | --- |
| `invalid_number` | Монголын 8 оронтой дугаар биш. | үгүй |
| `unallocated_number` | 8 оронтой боловч аль ч операторын хуваарилалтад байхгүй. | үгүй |
| `unsupported_operator` | ОНДО-гийн дугаар; энэ санд гарц нь байхгүй. | үгүй |
| `not_configured` | Операторын гарц бий, гэхдээ та тохиргоог нь өгөөгүй. | үгүй |
| `empty_message` | Текст хоосон. | үгүй |
| `message_too_long` | Тухайн гарцын хязгаараас урт (Скайтел, Жи-Мобайл: 160). | үгүй |
| `rejected` | Гарц хариу өгсөн боловч татгалзсан. Шалтгааныг `gatewayCode`, `response`-оос харна. | тийм |
| `timeout` | `timeoutMs` хугацаанд хариу ирээгүй. ⚠️ **Илгээгдсэн эсэх нь тодорхойгүй** — мессеж хүрсэн байж магадгүй. OTP-г дахин илгээхээсээ өмнө бодоорой. | тийм |
| `network` | Хүсэлт дуусаагүй (DNS, холболт татгалзсан, буруу хаяг). | тийм |

`sms.check({ to, message })` нь "үгүй" гэсэн мөрүүдийн шалгалтыг дангаар нь хийж, алдаа эсвэл
`null` буцаана. Мессеж үрэхээс өмнө формоо шалгахад тохиромжтой.

### Утасны дугаар

`to` нь 8 оронтой дугаар. `+976`, `976`, `00976`, хоосон зай, зураасыг автоматаар арилгана.
Туслах функцуудыг тусад нь ашиглаж болно:

```ts
import { gatewayFor, normalizePhone, operatorFor } from "mn-sms";

normalizePhone("+976 9911-2233"); // "99112233"
operatorFor("55501234");          // "mobicom"  (55 0–4 нь Юнител, 55 5–9 нь Мобиком)
gatewayFor("60112233");           // null       (ОНДО — гарц байхгүй)
```

### Дугаараа хадгалан шилжсэн хэрэглэгч

Монголд дугаараа хадгалан оператор солих боломжтой бөгөөд шилжсэн дугаар анхны
хуваарилалтдаа хэвээр үлддэг. Тиймээс хуваарилалтаар чиглүүлэхэд мессеж *хуучин*
оператор руу нь очиж, татгалзсан хариу авна. Шилжсэн дугаарын нээлттэй сан байхгүй тул
жинхэнэ операторыг нь мэдэж байвал өөрөө зааж өгнө:

```ts
await sms.send({ to: "99112233", message: "…", operator: "unitel" });
```

### Мессежийн урт ба өртөг

Нэг SMS-д латин үсгээр **160** тэмдэгт багтдаг бол ганц кирилл үсэг орсон даруйд ердөө
**70** болдог. Үүнээс урт мессеж хэд хэдэн хэсэгт хуваагдаж, хэсэг бүр тусдаа тооцогдоно.
Үүнд зориулсан хоёр туслах функц бий. `send()` эдгээрийг автоматаар ажиллуулахгүй — таны
өгсөн текст яг тэр чигээрээ илгээгдэнэ.

```ts
import { countSegments, toLatin } from "mn-sms";

countSegments("Сайн байна уу? Таны захиалга баталгаажлаа. Хүргэлт маргааш 14 цагт очно. Баярлалаа!");
// { encoding: "UCS-2", length: 83, segments: 2, perSegment: 67 }

const text = toLatin("Сайн байна уу? Таны захиалга баталгаажлаа. Хүргэлт маргааш 14 цагт очно. Баярлалаа!");
// "Sain baina uu? Tanii zahialga batalgaajlaa. Hurgelt margaash 14 tsagt ochno. Bayarlalaa!"
countSegments(text);
// { encoding: "GSM-7", length: 88, segments: 1, perSegment: 160 }

await sms.send({ to: "99112233", message: text });
```

`toLatin` нь монгол үгийг SMS-д түгээмэл бичдэг галигаар хөрвүүлнэ (`ө`, `ү` → `u`,
`ы` → `ii`, `х` → `h`). Мөн үнэтэй кодчилол руу чимээгүй шилжүүлдэг тэмдэгтүүдийг сольдог:
муруй хашилт, урт зураас, `…`, `№`, `₮`. Галигийг өөрчлөх бол `{ map: { ө: "o" } }` гэж
дамжуулна.

`countSegments` нь GSM стандартын тооцоо болохоос операторын нэхэмжлэх биш — хэрхэн
тоолдгийг оператороосоо лавлаарай. Скайтел, Жи-Мобайл хоёр кодчиллоос үл хамааран 160
тэмдэгтээс урт мессежийг шууд буцаадаг.

### Тохиргоо

```ts
createSmsClient(config, {
  timeoutMs: 20_000,   // анхны утга; Скайтелийн зааварт буй дээд хязгаар
  fetch: myFetch,      // тест хийх эсвэл proxy-оор дамжуулахад
});
```

## Операторуудаас юу авах шаардлагатай вэ

Доорх нь товч хувилбар. Гарц бүрийн хүсэлтийн хэлбэр, татгалзлын код бүр, юу нь
баримтжсан, юу нь баримтжаагүй тухай дэлгэрэнгүйг
**[docs/operators.mn.md](docs/operators.mn.md)** файлаас үзнэ үү.

**1. Оператор бүртэй гэрээ байгуулж, тусгай дугаар авна.** Оператор бүр бүртгэлтэй
байгууллагад "тусгай дугаар"-ын үйлчилгээг тус тусдаа худалддаг. Оператор тус бүртэй
гэрээ хийж, илгээгчийн богино дугаар болон API-ийн эрхээ авна. Илгээгчийн дугаар таны
бүртгэлд бэхлэгдсэн байдаг тул мессеж бүрт өөрөөр сонгох боломжгүй.

**2. Серверийнхээ гадаад IP хаягийг оператор бүрт бүртгүүлнэ.** Хүн бүр яг энэ шаардлага
дээр гацдаг. Дөрвөн гарц бүгд хүсэлт ирсэн IP хаягийг шалгадаг бөгөөд бүртгэлгүй хаягаас
ирсэн хүсэлтийг нэвтрэх мэдээлэл зөв байсан ч буцаана.

| Оператор | IP хаягаа хэрхэн бүртгүүлэх | Бүртгэлгүй хаягаас илгээвэл |
| --- | --- | --- |
| Юнител | Өөрөө, порталаас: Settings → API key → Hosts | татгалзана |
| Скайтел | Өөрөө, порталаас: Change configurations → Allowed IP List (цэгтэй таслалаар тусгаарлана) | `ERROR: 202 not authenticated` |
| Мобиком | Мобикомд хүсэлт гаргаж бүртгүүлнэ | татгалзана |
| Жи-Мобайл | Жи-Мобайлд хүсэлт гаргаж бүртгүүлнэ | `error3` |

Бодит байдал дээр энэ нь:

- **Тогтмол гадаад IP хаяг** хэрэгтэй. Гарах хаяг нь солигддог serverless платформ,
  автоматаар өргөждөг кластер зэрэг нь NAT gateway эсвэл тогтмол proxy-гүйгээр ажиллахгүй.
- IP нь бүртгэлгүй бол **таны компьютерээс ажиллахгүй**.
- Шинэ сервер эсвэл клауд руу нүүхдээ дөрвөн операторын жагсаалтыг *нүүхээсээ өмнө*
  шинэчилнэ.

**3. Нэг операторын гарц зөвхөн өөрийн хэрэглэгчид рүү хүргэнэ.** Скайтел үүнийг заавартаа
бичсэн байдаг (`ERROR: 206`); бусдыг ч мөн адил гэж тооцоорой. Монголын бүх гар утасны
дугаарт хүрэхийн тулд дөрвөн операторт дөрвүүлэнд нь бүртгэлтэй байх хэрэгтэй бөгөөд энэ
сангийн чиглүүлэлт яг үүнд зориулагдсан.

| | Юнител | Скайтел | Мобиком | Жи-Мобайл |
| --- | --- | --- | --- | --- |
| Нэвтрэх мэдээлэл | API key | бүртгэлийн дугаар `id` | `username` + `servicename` | `username` + `password` |
| Илгээгч | порталд тохируулна | `src` | `from` | `from` |
| Холболт | HTTPS, POST JSON | HTTPS, GET | HTTP, GET | HTTP, GET |
| Амжилттай хариу | HTTP 2xx | `OK` | `Sent` | `0: Accepted for delivery` |
| Татгалзсан хариу | 2xx биш | 200 дотор `ERROR: <код> …` | бусад бүх хариу | 200 дотор `error1`…`error6` |
| Дээд урт | баримтжаагүй | 160 тэмдэгт | баримтжаагүй | 160 тэмдэгт |
| Кирилл | нэг endpoint | тусдаа endpoint (автоматаар сонгоно) | нэг endpoint | нэг endpoint |
| Дугаар | 88 89 86 80, 50/55 0–4 | 90 91 96, 69-ийн хэсэг | 99 95 94 85, 50/55 5–9 | 98 0–1 ба 8–9, 93 97 83 0–1, 87 00–11 |

**ОНДО** (60, 66, 8181) дугаарын хуваарилалттай боловч энэ санд гарц нь байхгүй. Эдгээр
дугаар руу илгээхэд `unsupported_operator` буцна.

### Бодит орчинд гаргахаас өмнө мэдэх зүйлс

- **Мобиком, Жи-Мобайл хоёр энгийн HTTP ашигладаг.** Таны нэвтрэх мэдээлэл болон мессеж
  бүрийн агуулга сүлжээгээр шифрлэгдээгүй дамжина. Энэ нь операторын гарцын онцлог болохоос
  энэ сангийн сонголт биш.
- **`ok: true` гэдэг нь гарц мессежийг хүлээн авсан гэсэн үг, утсанд хүрсэн гэсэн үг биш.**
  Эдгээр API-ийн аль нь ч мессежийн дугаар эсвэл хүргэлтийн тайлан буцаадаггүй.
- **Энэ санд илгээлтийн хязгаарлалт, давхардал шалгалт байхгүй.** Нийтэд нээлттэй OTP
  endpoint нь дугаар тус бүрт хүлээх хугацаатай байх ёстой, эс бөгөөс таны SMS-ийн
  төлбөрийг хэн ч өсгөж чадна.
- **Урт кирилл мессеж илүү үнэтэй.** [Мессежийн урт ба өртөг](#мессежийн-урт-ба-өртөг)
  хэсгийг үзнэ үү.

## Нэг гарцыг шууд ашиглах

Чиглүүлэлт хэрэггүй бол оператор бүрийг тусад нь ашиглаж болно:

```ts
import { createSkytelGateway, resolveTransport } from "mn-sms";

const skytel = createSkytelGateway({ id, src }, resolveTransport());
await skytel.send("91112233", "hello"); // 8 оронтой болгосон дугаар авна
```

[docs/gateways.http](docs/gateways.http) файлд гарцуудыг кодгүйгээр шалгах түүхий HTTP
хүсэлтүүд бий.

## Хөгжүүлэлт

```bash
npm install
npm test          # node:test, fetch-ийг орлуулсан — юу ч илгээгдэхгүй
npm run typecheck
npm run build     # dist/ — ESM, CJS, төрлийн тодорхойлолт
```

Бодит гарц руу илгээдэг тест байхгүй: жинхэнэ илгээлт мөнгө зарцуулж, бодит хэрэглэгчид
хүрдэг бөгөөд зөвхөн бүртгэлтэй IP хаягаас л ажилладаг.
